# Product Overview

RESERVE Admin Dashboard is an email campaign management platform that enables users to create, manage, and track email marketing campaigns with AI-powered copy variations.

## Core Features

- Email campaign creation and management
- Lead upload and qualification tracking
- SMTP server configuration
- Campaign batch processing with configurable sizes
- AI-powered and manual copy variation support
- Funnel-based campaign workflows
- Real-time analytics (open rates, click rates)
- Lead screening and temperature analysis
- Abandoned cart tracking
- Multi-language support (internationalization with next-intl)

## User Roles

- Admin users with authentication
- Dashboard-based interface for campaign management

## Key Workflows

1. Campaign Setup: Create campaign → Upload leads → Configure copy variations → Set batch size → Start campaign
2. Lead Management: Import leads → Screen/qualify → Track engagement → Analyze temperature
3. Analytics: Monitor campaign performance, delivery metrics, and engagement rates
